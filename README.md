## Опис проєкту

Проєкт описує AI-агента, який допомагає створити кросплатформний застосунок
«Hello, World!» мовою Python, підготувати його збирання та перевірити за
допомогою `pytest`. Агент організовує роботу через послідовність команд і
пов'язані з ними skills.

## Як запустити агента

1. Відкрийте репозиторій у VS Code.
2. Відкрийте Copilot Chat і виберіть режим **Agent**.
3. Виконайте команду `/init`, щоб почати роботу агента.

Опис будови агента наведений у [docs/architecture.md](docs/architecture.md).

## Як зібрати і запустити hello

Окремий етап компіляції для Python-програми не потрібен. Перейдіть у каталог
застосунку та встановіть `pytest`:

```shell
python -m pip install pytest
```

Запустіть тести:

```shell
python -m pytest
```

Щоб запустити програму, передайте інтерпретатору шлях до створеного Python-
скрипту:

```shell
python <шлях-до-файлу-програми>.py
```

У Windows замість `python` за потреби використовуйте `py -3`. Фактичний шлях
до скрипту залежить від результату створення проєкту.
