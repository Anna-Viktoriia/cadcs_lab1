## Опис проєкту

Проєкт описує AI-агента, який допомагає створити кросплатформний застосунок
«Hello, World!» мовою Python, підготувати його збирання та перевірити за
допомогою `pytest`. Агент організовує роботу через послідовність команд і
пов'язані з ними skills.

## Як запустити агента

1. Відкрийте репозиторій у VS Code.
2. Відкрийте Copilot Chat і виберіть режим **Agent**.
3. Виберіть агента **Build Engineer**.
4. Виконайте команду `/lab1-init`, щоб почати повний сценарій.

Опис будови агента наведений у [docs/architecture.md](docs/architecture.md).

## Як зібрати і запустити hello

Після створення проєкту запустіть CI-скрипт із кореня репозиторію. Він
створить `.venv`, встановить залежності у віртуальне середовище, запустить
тести й збере застосунок:

```shell
./ci.sh
```

У Windows використовуйте:

```bat
ci.bat
```

Докладні інструкції зі запуску тестів і програми наведені в
[docs/usage.md](docs/usage.md).
