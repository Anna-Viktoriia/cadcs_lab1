# Використання агента та запуск проєкту

## Запуск агента у VS Code

1. Відкрийте репозиторій проєкту у VS Code.
2. Відкрийте **Copilot Chat**.
3. У виборі режиму чату оберіть **Agent**.
4. Виберіть агента **Build Engineer**.
5. У полі чату виконайте `/lab1-init`.
6. Дочекайтеся завершення послідовних етапів `git-init`,
   `create-project`, `create-build`, `create-actions` і `check`. Якщо агент
   зупиниться на помилці, виправте вказану причину перед повторним запуском.

## Локальна перевірка

Після того як агент створив скрипти, виконуйте команду з кореня репозиторію.

**Linux/macOS:**

```shell
./ci.sh
```

**Windows:**

```bat
ci.bat
```

Скрипти створюють `.venv`, встановлюють залежності у віртуальне середовище,
запускають тести та збирають застосунок у `dist/`. Успішний тест
`test_basic_addition` має показати статус `passed`.

## Запуск програми

### Скриптом запуску

Із кореня репозиторію:

**Linux/macOS:**

```shell
./run.sh
```

**Windows:**

```bat
run.bat
```

### Командою Python у активованому venv

Спершу створіть середовище, якщо його ще немає, і встановіть залежності
локальним CI-скриптом (`./ci.sh` на Linux/macOS або `ci.bat` на Windows).
Потім активуйте середовище та запустіть модуль із каталогу `src/`, де
розташований пакет `hello`.

**Linux/macOS (Bash або Zsh):**

```shell
source .venv/bin/activate
cd src
python -m hello
```

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
Set-Location src
python -m hello
```

### Запуск зібраного файла

Після успішної збірки з кореня репозиторію:

**Linux/macOS:**

```shell
./dist/hello
```

**Windows:**

```bat
dist\hello.exe
```

## Очікуваний вивід

Команда запуску через `run.sh`, `run.bat`, `python -m hello` або зібраний
виконуваний файл має надрукувати:

```text
Hello, World!
```

## Наявність команд у репозиторії

Файли `ci.sh`, `ci.bat`, `run.sh`, `run.bat`, пакет `src/hello` і готові
виконувані файли в `dist/` створюються під час роботи агента. Якщо потрібного
файла ще немає, спочатку запустіть `/lab1-init`; команди вище застосовні після
успішного створення відповідних файлів.
